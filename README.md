# Personal Portfolio

Personal website of Julio Alfredo Vázquez Díaz, available in Spanish and English. It showcases an introduction, projects, skills, professional profiles, and contact information.

## Features

- Responsive design for mobile and desktop.
- Language switch between the Spanish and English versions.
- Image gallery for the Lakitu project.
- Links to professional profiles, contact options, and a downloadable CV.

## Technologies

HTML, CSS, and JavaScript, with no frameworks or dependencies to install.
