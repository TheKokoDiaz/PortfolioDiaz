Proyectos

Panel de control de vacaciones

Tecnologías usadas: PHP, MySQL, HTML, JS y CSS

Diseñar una página web para administrar los días vacacionales de todos los empleados de la empresa, utilizando una base de datos para organizar la información y habilitar la inserción, edición y eliminación de datos solo a los supervisores. La página muestra a todos los empleados e indica los días vacacionales otorgados por antigüedad, cuantos quedan disponibles y cuantos se han utilizado.

Robot de acompañamiento para personas con discapacidad visual

Tecnologías usadas: Electrónica, Jetson Nano y Python

Crear la base de un robot prototipo, que aplica redes neuronales para el análisis de su entorno y la identificación de objetos, con el objetivo de guiar a personas con discapacidad visual. Este proyecto se avanzó lo suficiente para que el prototipo fuera capaz de identificar figuras geométricas básicas y mantener distancia de una persona.
